Kebijakan Privasi — Agent SMC Uploader

Terakhir diperbarui: 24 November 2026
Aplikasi: Agent SMC Uploader — alat bantu pengunggah video untuk channel YouTube @agentic_smart
Kontak: erikz.rc@gmail.com

1. Tentang aplikasi ini

Agent SMC Uploader adalah aplikasi yang membantu pemilik channel YouTube @agentic_smart mengunggah video Shorts dan video long-form ke channel miliknya sendiri melalui YouTube Data API v3. Aplikasi ini dipakai sendiri oleh pemilik channel; tidak ditawarkan ke publik sebagai layanan.

2. Izin (scope) yang digunakan

Aplikasi ini hanya meminta dua izin dari Google:

  • https://www.googleapis.com/auth/youtube.upload — mengunggah video ke channel pengguna.
  • https://www.googleapis.com/auth/youtube.force-ssl — mengelola video yang diunggah (mis. menambah ke playlist dan mengatur jadwal tayang).

Tidak ada izin lain yang diminta. Aplikasi ini tidak membaca daftar subscriber, komentar, analitik, atau data channel lain di luar yang diperlukan untuk mengunggah video.

3. Data yang kami kumpulkan

Kami tidak mengumpulkan, menyimpan, membagikan, atau menjual data pribadi apa pun. Secara khusus:

  • Tidak ada data pengguna yang dikirim ke server kami — karena kami tidak mengoperasikan server untuk aplikasi ini.
  • Token akses OAuth (izin dari akun Google pemilik channel) hanya disimpan secara lokal di perangkat pemilik channel dan tidak dibagikan ke pihak mana pun.
  • File video yang diunggah dikirim langsung dari perangkat pemilik channel ke YouTube melalui API resmi Google; kami tidak menyimpan salinannya.

4. Pihak ketiga

Satu-satunya pihak ketiga yang terlibat adalah Google / YouTube, melalui YouTube Data API v3, sesuai Kebijakan Privasi Google. Aplikasi ini tidak memakai iklan, pelacak (tracker), atau layanan analitik pihak ketiga.

5. Keamanan

Token dan kredensial OAuth disimpan dengan izin file terbatas (mode 600) di perangkat pemilik channel dan tidak pernah ditulis di chat, log, atau repositori publik.

6. Anak-anak

Aplikasi ini tidak ditujukan untuk anak-anak dan tidak mengumpulkan data anak-anak.

7. Perubahan kebijakan

Jika kebijakan ini berubah, tanggal "Terakhir diperbarui" di atas akan diubah dan perubahan akan tercatat di halaman ini.

8. Kontak

Privacy Policy — Agent SMC Uploader (Summary in English)

Last updated: November 24, 2026

Agent SMC Uploader helps the owner of the YouTube channel @agentic_smart upload videos to their own channel via the YouTube Data API v3. It uses only two Google OAuth scopes: youtube.upload and youtube.force-ssl. We do not collect, store, share, or sell any personal data. OAuth tokens are stored locally on the channel owner's device only. Videos are sent directly from the owner's device to YouTube; we keep no copies. No ads, no third-party trackers, no analytics. The only third party involved is Google / YouTube, governed by the Google Privacy Policy. Contact: erikz.rc@gmail.com.
